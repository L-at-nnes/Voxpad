# Voxpad UI

Vue 2 + TypeScript frontend of [Voxpad](https://github.com/L-at-nnes/Voxpad). It is built to static files and embedded in the Tauri executable; see the [architecture overview](../docs/architecture.md).

```
npm install      # install dependencies
npm run build    # production build into dist/ (embedded by the Rust build)
npm run lint     # lint and fix
npm run test:unit
```

Contribution guidelines are in the [main repository](https://github.com/L-at-nnes/Voxpad/blob/master/CONTRIBUTING.md).
